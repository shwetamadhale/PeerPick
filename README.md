PeerPick
A social recommendation platform where users can share, review, and discover media (movies, books, music, etc.) within specific groups of people, such as friends or family.

Features
User Authentication: Users can sign up, log in, and manage their profiles.
Group Creation & Invitation: Create groups for specific people (e.g., family, friends) and invite members.
Recommendation Sharing: Users can add media recommendations, including text reviews, tags, and ratings.
Tagging & Filtering: Media recommendations are tagged with genres and themes for easy filtering.
Feed: View a feed of all recommendations from your groups, with options to like or dislike.
Search & Sort: Search for recommendations by media type, tags, or user reviews.
Tech Stack
Frontend: React.js (or Vue.js)
Backend: Node.js with Express (or Django)
Database: MongoDB
Authentication: Firebase Auth or Passport.js
Hosting: Vercel/Netlify (Frontend), Heroku/DigitalOcean (Backend)
Image Storage: Cloudinary or AWS S3 for media uploads
